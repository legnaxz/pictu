# 스플렌더 포켓몬 개인 팬 프로젝트

스플렌더: 포켓몬의 전용 규칙을 구현한 비상업적 개인 플레이 프로토타입입니다.

- Pokémon 캐릭터명과 원격 공식 아트워크 URL은 각 권리자에게 귀속됩니다.
- Splendor 및 관련 게임 구성 요소의 권리는 각 권리자에게 귀속됩니다.
- 본 프로젝트는 권리자와 제휴·후원·승인 관계가 없으며, 판매·배포·수익화를 목적으로 하지 않습니다.
- `보드`와 `TUI` 버튼은 동일한 게임 상태를 즉시 전환합니다.
- TUI는 브라우저 안에서 제공되는 텍스트 중심 조작 화면입니다.
- 1/2/3단계 35/30/15장과 희귀 5장, 전설·환상 5장을 각각 공개합니다.
- 희귀·전설·환상은 손에 보관할 수 없고, 포획에 마스터볼이 필요합니다. 마스터볼은 일반 포켓몬 구매에는 쓸 수 없습니다.
- 턴 종료 전 진화 1회(모든 색 1개 할인, 점수·보너스 정상 획득)와 18점 최종 라운드를 적용합니다.
- 트레이너 카드 8종(지우·이슬이·웅이·민화·강연·나츠메·그린·마티스)을 고르면 시작 보너스 1개와 고유 특전을 얻습니다. 한 판에 트레이너는 중복되지 않습니다.
- 체육관 배지를 플레이어 수 + 1개 공개합니다. 영구 보너스 조건을 먼저 채운 트레이너가 각 ★3점을 선점합니다.
- 카드마다 `⚡잡기`·`🎒보관` 버튼과 지불 가능 여부(부족한 볼 색·수량)를 표시합니다.
- 우측 `내 포켓몬 도감`에서 포획·진화한 카드를 색상별로 확인할 수 있습니다.
- 사운드는 오디오 파일 없이 Web Audio API로 합성합니다. 상단 🔊 버튼으로 끄고 켤 수 있으며 설정은 브라우저에 저장됩니다.
- 포획 시 포켓볼 투척, 볼 획득·카드 이동, 배지 획득 배너, 승리 축포 등의 연출이 재생됩니다.
- `prefers-reduced-motion: reduce` 환경에서는 애니메이션을 자동으로 비활성화합니다 (사운드와 결과 화면은 유지).
- CPU 진행 속도를 느림·보통·빠름 중에서 고를 수 있습니다 (기본값 보통). 상단 속도 버튼으로 게임 중에도 즉시 바꿀 수 있습니다.

실행은 `npm start` 후 `http://localhost:4174`에서 할 수 있습니다.
